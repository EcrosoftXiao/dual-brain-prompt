# 双脑协同开发协议 (Dual-Brain Protocol)

本工程采用 **双脑协同体系**：
- **脑一 (Local M4)**: 本地 Mac mini M4 上运行的 `prompt-architect` (14B)，负责**意图拆解、提示词专业化重构、敏感词边界隔离、零成本无限次推演**。
- **脑二 (Antigravity)**: 负责**全工程代码检索、多文件协同编辑、单元测试驱动与高阶架构落地**。

## 协同触发准则

1. **粗糙需求自动提纯**:
   当用户在当前工程中给出简短、粗糙或缺乏边界条件的需求（如“帮我写个用户鉴权”或“优化一下这块代码”）时，优先使用 `local-prompt-refine` 技能调用本地 M4 模型进行深度提示词结构化提纯。

2. **生产级 Prompt 结构**:
   从本地模型产出的 Prompt 必须严格遵循 `Role`（角色定位）、`Context`（工程上下文）、`Tasks`（明确步骤）、`Constraints`（负向防幻觉约束）与 `Output Format`（输出格式）。

3. **双脑分工边界**:
   - 不将大量未清洗的原始 Prompt 直接提交给云端大模型，确保先经过本地 14B 模型的架构优化。
   - Antigravity 聚焦于执行本地模型提纯后的精准指令，确保代码交付的高确定性。
